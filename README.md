Portfolio Professionnel de Kingson Guerrier

ce portfolio professionnel est développé dans le cadre d'un cours de Conception et
programmation de sites Web I (DUT en TIC, ISTEAH, Été 2026).

Ce site présente mon parcours académique, mes compétences
techniques, mes expériences professionnelles, mes projets et mes certifications — destiné à être
utilisé lors de candidatures à des stages, emplois, programmes internationaux et collaborations
professionnelles.

Application en ligne : [lien Railway à venir]
Dépôt GitHub : https://github.com/K-GENERATION/KG-PORTFOLIO-FULLSTACK


Aperçu de la plateforme

Page et Description

Accueil: Hero animé, citations rotatives, organigramme des domaines d'expertise, résumé biographique, statistiques
Biographie: Présentation détaillée en 3 sections (parcours, expérience, mission/vision)
Expériences: Onglets : expériences professionnelles (timeline), formations académiques, compétences (accordéon), certifications (galerie) |
Projets:  Galerie filtrable par catégorie, cartes interactives, timeline d'évolution
Contact: Formulaire de contact avec validation et sauvegarde serveur

Technologies utilisées

Frontend
React (Vite)
React Router v6  : navigation SPA
Context API — gestion des états globaux (thème, langue)
CSS3 pur (Flexbox, Grid, animations): sans framework tiers

Backend
Node.js
Express.js
Persistance des messages de contact au format JSON

Outils & Déploiement
Git / GitHub : versionnage des codes
Railway|hébergement et déploiement continu
Vite | bundler et serveur de développement

 Fonctionnalités

Navigation fluide sans rechargement de page (React Router v6)
Mode sombre / mode clair (Context API)
Sélecteur de langue (FR / HT / EN)
Design entièrement responsive (desktop, tablette, mobile)
Animations CSS pures (flottement, fondu, accordéon, hover)
Galerie de projets avec filtrage dynamique par catégorie
Compétences affichées sous forme de barres de progression et graphiques
Formulaire de contact avec validation côté client et serveur
Persistance des messages dans un fichier `messages.json`
Architecture par composants réutilisables et modulaires
